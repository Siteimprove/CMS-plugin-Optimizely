# 4.3.6 release candidate

Changes since the public 4.3.5 package in this repository.

## Fixes

- **Saving settings no longer leads to a 404.** On sites that register a conventional MVC route such as `{controller}/{action}/{id?}`, clicking Save or enabling the pre-publish check on the settings page used to redirect to `/SiteimproveAdmin` instead of the plugin's page under the CMS module path. Both actions now return to the plugin's settings page. When the pre-publish check can't be enabled, the error message is still shown. (PR #15)
- **Regional language pages resolve to the right URL.** When an editor selects a regional language such as `en-US` for content that falls back to another language, the plugin loads the content using the configured fallback rules and looks up its regional public URL. (PR #16)

## Scope and known limitations

This candidate targets Optimizely CMS 12. The CMS 13 line (`feature/cms13`, 5.0.0-beta.1) does not include the settings redirect fix.

Manual installation and acceptance testing of the candidate on the Windows demo instance are required before publication. For the redirect fix, include a host site that registers a conventional MVC route, and check that saving the settings and enabling the pre-publish check both return to the plugin's settings page.
