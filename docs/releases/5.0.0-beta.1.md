# 5.0.0-beta.1 — Optimizely CMS 13 beta

Beta for non-production evaluation on Optimizely CMS 13 and .NET 10. This GitHub prerelease is separate from the CMS 12 / 4.x release line and does not publish to NuGet.org or the Optimizely feed.

## Changes

- Port the integration to CMS 13, including Visual Builder context, application URL resolution, authorization and module packaging.
- Add the CMS 12 beta's shared-block Prepublish workflow. Blocks show only Prepublish; returning to a page restores the published-page context. All Properties can capture a temporary same-origin block preview supplied by the site.
- Remove floating preview lifecycle notifications. Check-start errors are returned to the Siteimprove panel.
- Use the Siteimprove v2 SDK with automatic connection setup. Subscription access follows the signed-in Siteimprove account; CMS settings no longer require legacy API credentials or an activation step.
- Preserve public-origin mappings, validate settings saves and invalidate stale draft captures/highlights. Publishing no longer triggers automatic plugin rechecks.

## Validation and scope

Beta.1 packages the alpha.13 implementation under a beta version with release documentation; its runtime client script bytes are unchanged. Automated server, JavaScript/Chromium and package/consumer checks are repeated for the release candidate. The release assets record its exact commit, package checksum, dependency audit and GitHub validation run.

The predecessor alpha.13 passed 35 C# checks, 60 JavaScript/Chromium checks and 53 real HTTP acceptance checks on a private CMS 13.0.0 host. On the Windows CMS 13.0.2 demo, the real SDK detected a missing image alternative in an unpublished shared block, then cleared it after a persisted correction and fresh All Properties scan without publishing. The accessibility count fell from 2 to 1. Those live author checks used alpha.13, not the renamed beta package. See [the demo validation record](../cms13-demo-validation.md).

## Known issues

- A block check attempted after switching to the visible preview failed to start. That path and real block highlighting are not release-verified; the recorded scan/fix/recheck used All Properties.
- Site-supplied same-origin HTML previews are required. Cross-origin previews, inline blocks, media and missing preview templates are excluded. A fragment result does not establish accessibility in every containing page.
- The demo's Alloy preview required conversion from the old content-area DisplayFor helper to CMS 13 property/item tag helpers. This host-template change is not included in the plugin package. Host CSP must also permit the CMS and SDK resources and connections it uses.
- The CMS dependency graph selects ImageSharp 3.1.12 with reported advisories. They remain unresolved; the dependency report is attached. Use an isolated environment with synthetic content. Do not suppress the warnings or infer that this release resolves them.
- Opti ID/Graph, complete CMS 12 settings migration, real entitlement-denial/outage recovery and the full browser/site compatibility matrix remain open. This is not a supported production release.

Follow [installation and rollback](5.0.0-beta.1-installation.md). Report reproducible beta findings through the repository's Issues page, including plugin/CMS/browser versions, editor view and sanitized steps. Do not include credentials, cookies, preview tokens or private page HTML.
